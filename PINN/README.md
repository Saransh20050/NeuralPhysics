# Physics-Informed Neural Networks (PINNs)

Physics-Informed Neural Networks (PINNs) are neural networks trained to solve differential equations by embedding the governing laws of physics directly into the learning process.

Instead of relying solely on labeled data, PINNs leverage physical constraints—such as differential equations, boundary conditions, and initial conditions—to guide training through automatic differentiation.

This directory contains from-scratch implementations of PINNs for a variety of ordinary and partial differential equations, with the goal of building an intuitive understanding of Scientific Machine Learning.
